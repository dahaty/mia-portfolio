# Аудио 15 практик «Хочу ему написать»

Положи сюда записи практик — кнопка «Включить» на экране практики подхватит их сама.

- Имя файла: `calm-NN.m4a`, NN — номер практики из документа «15 практик быстрого успокоения» (две цифры): `calm-01.m4a` … `calm-15.m4a`.
- Формат: m4a (AAC) — играет везде, включая iPhone, и при заблокированном экране.
- `calm/` — испанские записи, `calm-ru/` — русские (для `/ru/`).
- Пока файла нет, на экране только описание практики и строка, что аудио скоро появится.
